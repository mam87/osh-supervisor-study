# موسوعة مشرف السلامة — منصة دراسية شاملة

منصّة ويب ثابتة (Static Site) لتحضير امتحان **مشرف فني السلامة والصحة المهنية** في الأردن، مبنية على محتوى معهد السلامة والصحة المهنية (مؤسسة التدريب المهني الأردنية) كاملًا — **١٨ وحدة تدريبية**، منظّمة ومبسّطة وقابلة للبحث الفوري.

**إعداد: مأمون السعودي** — تم بناء المحتوى والمنصّة بمساعدة Claude.

🔗 الموقع المباشر (بعد تفعيل GitHub Pages، انظر أدناه): `https://mam87.github.io/osh-supervisor-study/`

## المزايا

- **١٨ وحدة كاملة**: من إدارة السلامة إلى إعداد التقارير، كل وحدة بشكلها الكتابي القابل للقراءة المتواصلة (وليس شرائح منفصلة فقط) مع فهرس جانبي للتنقّل السريع.
- **الملخص الشامل للامتحان** (`summary.html`): ملخص مركّز للاختيار من متعدد لكتب المعهد السبعة عشر، وقانون العمل وأنظمة وتعليمات 2023 والضمان الاجتماعي — مع المعادلات (KaTeX) والأرقام والأفخاخ الشائعة ومفاتيح بنوك الأسئلة.
- **بحث فوري شامل** (`quiz.html` / الرأس العلوي في كل صفحة): يبحث في نص كل الوحدات معًا ويقفز مباشرة للفقرة المطلوبة، مع دعم تطبيع الحروف العربية (أ/إ/آ/ا، ة/ه، ى/ي) لنتائج أدق.
- **بنك أسئلة شامل** (`quiz.html`): ٢٧٠ سؤال (اختيار من متعدد + صح/خطأ) من كل الوحدات، بوضع تدريب تفاعلي مع تصحيح فوري ونتيجة.
- **مرجع الأرقام والقيم** (`numbers.html`): كل الأرقام والنسب والحدود القانونية من كل الوحدات في جدول واحد قابل للفرز والبحث — مثالي لليلة الامتحان.
- **وضع ليلي/نهاري**، تصميم متجاوب للجوال، ودعم كامل للطباعة (كل وحدة قابلة للطباعة كملف مرجعي).

## البنية التقنية

```
osh-site/
├── index.html          # الصفحة الرئيسية (شبكة الوحدات + بحث)
├── unit.html            # صفحة عرض وحدة واحدة (?u=1 .. ?u=18)
├── quiz.html            # بنك الأسئلة التفاعلي
├── numbers.html         # مرجع الأرقام المجمّع
├── summary.html         # الملخص الشامل (مولَّد من content/ عبر scripts/build_summary.py)
├── content/             # مصدر الملخص بصيغة Markdown (يُعدَّل يدويًا)
├── assets/
│   ├── style.css        # التصميم الموحّد لكامل الموقع
│   └── app.js            # البحث، الوضع الليلي، تحميل البيانات
├── data/                 # JSON مبني آليًا من الوحدات (لا يُعدَّل يدويًا)
│   ├── catalog.json
│   ├── unit-1.json ... unit-18.json
│   ├── questions.json
│   ├── numbers.json
│   └── search-index.json
└── scripts/
    └── build.py          # سكربت بايثون يُنشئ data/ من ملفات الوحدات المصدرية
```

الموقع **ثابت بالكامل** (HTML/CSS/JS فقط، بدون Backend) ويعمل مباشرة من GitHub Pages بدون أي خطوة بناء (build step) عند النشر — بيانات `data/*.json` مُولَّدة مسبقًا ومرفوعة مع المشروع.

## تشغيل محلي

```bash
cd osh-site
python3 -m http.server 8080
# افتح http://localhost:8080
```

## إعادة توليد البيانات (عند تحديث محتوى وحدة)

يعتمد `scripts/build.py` على ملفات HTML المصدرية لكل وحدة (خارج هذا المستودع). إذا توفّرت هذه الملفات محليًا:

```bash
pip install beautifulsoup4
python3 scripts/build.py
```

سيُعيد توليد كل ملفات `data/*.json`.

لتحديث صفحة الملخص الشامل: عدّل `content/summary-books.md` أو `content/summary-legislation.md` ثم:

```bash
pip install markdown
python3 scripts/build_summary.py
```

## تفعيل GitHub Pages

1. اذهب إلى **Settings → Pages** في المستودع.
2. تحت **Build and deployment**: اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)`.
4. احفظ — الموقع سيكون متاحًا خلال دقيقة على: `https://mam87.github.io/osh-supervisor-study/`

## إخلاء مسؤولية

المحتوى إعادة صياغة وتبسيط تعليمي لمواد معهد السلامة والصحة المهنية الرسمية بغرض المساعدة على المراجعة والتحضير للامتحان، وقد يحتوي على معلومات إضافية موضّحة صراحة في مصدرها. يُنصح دائمًا بالرجوع إلى الكتب والمناهج الرسمية كمرجع نهائي.
